Help & About

Training use only

This app is a proficiency aid. It is not an accredited messaging or hazard-prediction system. Do not let its output drive operational decisions. The yellow banner is mandatory and cannot be hidden.

What it does

Module 1 — Report Builder/Parser. Construct CHEM NBC1/2/3 reports from form fields, or paste a report string and have each set decoded into labeled fields. Validation is per the manual's set / field / enumeration definitions. Anything the source doesn't pin down is tagged UNVERIFIED rather than guessed.

iPhone notes

  • Copy to clipboard is the reliable mobile path. File save / import on iOS Safari works through the Files app via the share sheet but is clunkier.
  • Use Add to Home Screen from Safari's share sheet for a clean full-screen shell. The app runs entirely offline once loaded.
  • State is held in memory only. Use Save scenario to persist work between sessions — iOS Safari evicts localStorage, so this app does not depend on it.

Citations

All field, type, enumeration, and per-report set membership definitions come from FM 3-11.3 / MCWP 3-37.2A / NTTP 3-11.25 / AFTTP(I) 3-2.56, 2 Feb 2006 (Tables III-1, III-2, III-3, III-4 and Appendix E sample reports — Figures E-1, E-2, E-3).
