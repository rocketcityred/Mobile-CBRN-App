Help & About

Training use only

This app is a proficiency aid. It is not an accredited messaging or hazard-prediction system. Do not let its output drive operational decisions. The yellow banner is mandatory and cannot be hidden.

What it does

Module 1 — Report Builder/Parser. Construct CHEM NBC1/2/3 reports from form fields, or paste a report string and have each set decoded into labeled fields. Validation is per the manual's set / field / enumeration definitions. Anything the source doesn't pin down is tagged UNVERIFIED rather than guessed.

iPhone notes

  • Copy to clipboard is the reliable mobile path. File save / import on iOS Safari works through the Files app via the share sheet but is clunkier.
  • Use Add to Home Screen from Safari's share sheet for a clean full-screen shell. The app runs entirely offline once loaded.
  • State is held in memory only. Use Save scenario to persist work between sessions — iOS Safari evicts localStorage, so this app does not depend on it.

Citations

All field, type, enumeration, and per-report set membership definitions come from FM 3-11.3 / MCWP 3-37.2A / NTTP 3-11.25 / AFTTP(I) 3-2.56, 2 Feb 2006 (Tables III-1, III-2, III-3, III-4 and Appendix E sample reports — Figures E-1, E-2, E-3).

Active standard

The STD pill in the title bar toggles between the default AFTTP(I) 3-2.56 (2 Feb 2006) joint US standard and the latest NATO ATP-45 Edition E, Version 1 (January 2014; STANAG 2103). With ATP-45(E) active the app re-labels reports as CBRN 1/2/3 CHEM, accepts the modern CDM set names (WHISKEYM/XRAYM/YANKEEM), treats previously-unverified delivery / container codes as canonical, and exposes a Type D (industrial / TIM release) template in the plotter (1 km release, 3 km hazard area). Report-set internals (ALFA/BRAVO/…) and the Type A/B/C hazard-distance numbers are unchanged between the two standards.

Home › Module 2 — CDM Parse

Chemical Downwind Message

Extract the three plotting-critical values — downwind direction (grid), downwind speed, air stability code — that drive Module 3. The exact CDM line/set format is an open item (M2-OI-1): the parser uses the shared tokenizer and surfaces fields it can identify; anything ambiguous is flagged UNVERIFIED. Until the CDM format is transcribed from the manual, "Quick CDM" is the primary entry path.

Quick CDM entry

Enter the three values Module 3 needs. Direction is the grid downwind azimuth (degrees, where the wind is blowing TO). Speed is in km/h. Stability category is the numeric code from the message (typically 1–7).

Chemical Simplified Hazard Plotting

Schematic, north-up plot per FM 3-11.3 Appendix E (Table E-1, Figures E-5…E-13). SCHEMATIC ONLY — no map basemap (per requirements M3.2). All distances are doctrinal templates; the plot is a training aid, not an operational hazard prediction.

1. Attack source

Per ATP-45(E) §0319: TIM / chemical-substance release uses a 1 km release radius and a 3 km hazard area (concentric at wind ≤ 10 km/h, 30° wedge of DHD = 3 km at wind > 10 km/h). Overrides Type A/B/C selection.

A line attack requires ≥2 FOXTROT grids. For the schematic the attack-line orientation is taken from "attack-line bearing" below; grid strings are used for labels only.
